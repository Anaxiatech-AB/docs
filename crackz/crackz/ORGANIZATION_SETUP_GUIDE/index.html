    2. Security & Compliance Settings 🔒¶

    Two-Factor Authentication (2FA)¶

    # Require 2FA for all organization members
gh api -X PATCH orgs/Anaxiatech-AB --field two_factor_requirement_enabled=true

    Security Policies¶

    • Dependency Security: Enable Dependabot alerts
    • Secret Scanning: Enable for all repositories
    • Code Scanning: Enable GitHub Advanced Security (if upgraded to Enterprise)

    Repository Security Settings¶

    # Set secure defaults for new repositories
gh api -X PATCH orgs/Anaxiatech-AB --field members_can_create_repositories=false
gh api -X PATCH orgs/Anaxiatech-AB --field default_repository_permission=none

    7. Development Workflow Enhancements ⚡¶

    Organization-Wide Actions¶

    Create .github repository with reusable workflows: 

    # .github/workflows/security-scan.yml
name: Security Scan
on:
  workflow_call:
    inputs:
      language:
        required: true
        type: string

jobs:
  security:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run CodeQL
        uses: github/codeql-action/analyze@v2
        with:
          languages: ${{ inputs.language }}
