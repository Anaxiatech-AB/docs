    Printable / PDF Export¶

    📄 Crackz Full Documentation · Anaxiatech AB

    Generate (or after deployment, download) a single PDF containing the full Crackz documentation, enriched with an outline, styled cover (hero image + logo), bookmarks, and footer page numbers.

    The PDF is produced at: site/crackz-docs.pdf after you run an export (not committed). On GitHub Pages deployment you can also upload it as an artifact.

    The cover automatically injects the current project version from pyproject.toml and © Anaxiatech AB.

    Quick Command¶

    If you have dev dependencies installed (Playwright included): 

    uv run task pdf
    This runs: 1. mkdocs build --clean --strict 2. python scripts/export_pdf.py (headless Chromium via Playwright)

    Output: 

    site/crackz-docs.pdf

    Makefile Target¶

    Alternatively: 

    make docs-pdf
    (Installs Chromium if needed and exports the PDF with outline + cover image.)

    Fast Minimal (no cover/outline)¶

    uv run task pdf_fast
    Outputs: site/crackz-docs-fast.pdf

    PowerShell (Windows) Helper¶

    pwsh scripts/windows/export_pdf.ps1 -Outline -CoverTitle "Crackz Documentation"
    (Add -NoCover or -NoHeader as needed.)

    Manual Steps (Detailed)¶

    uv run mkdocs build --clean --strict
uv run playwright install chromium   # one time
uv run python scripts/export_pdf.py \
  --outline \
  --cover-image 'assets/crackz-logo.png' \
  --logo 'assets/crackz-logo.png' \
  --cover-title 'Crackz Documentation' \
  --cover-subtitle 'AI Image Analysis' \
  --out site/crackz-docs.pdf

    Custom Output Path¶

    uv run python scripts/export_pdf.py --out site/my-custom-docs.pdf

    Troubleshooting¶

    Issue Resolution
    Blank / tiny PDF Ensure pages appear in nav: and build succeeded.
    Image missing on cover Verify path & extension; ensure it is PNG and relative to project root.
    Bookmarks missing Remove --no-bookmarks; ensure PyPDF2 installed (dev group).
    Header links (¶) showing CSS now hides them in synthesized print page.
    No revision dates Commit files so the git plugin has history.

    How It Works¶

    If the print-site plugin combined page is absent/empty, the exporter synthesizes a combined HTML page by extracting each built page’s <article> content in navigation order, then applies a print-focused stylesheet (gradient headings, subdued body text, dual-column outline) and inlines images.

    CI Integration¶

    - name: Build docs + PDF
  run: |
    uv sync --dev
    uv run mkdocs build --clean --strict
    uv run playwright install chromium
    uv run python scripts/export_pdf.py --outline --cover-image 'assets/crackz-logo.png' --logo 'assets/crackz-logo.png' --out site/crackz-docs.pdf
- uses: actions/upload-artifact@v4
  with:
    name: crackz-docs-pdf
    path: site/crackz-docs.pdf

    Download (after deployment)¶

    Typical URL (GitHub Pages): 

    https://<your-user>.github.io/crackz/crackz-docs.pdf

    Open an issue for further enhancements (searchable text improvements, watermarking, or multi-theme variants).
