    Easy Install Guide¶

    This guide provides the simplest installation methods for end users. Choose the method that best fits your needs:

    • Option A: Wheel Installation - If you have Python installed
    • Option B: Standalone Executable - No Python required (easiest!)

    Option A: Wheel Installation (.whl)¶

    Requirements¶

    • Python 3.11, 3.12, or 3.13 (64-bit)
    • Windows, macOS, or Linux
    • GitHub account with repository access (contact theresia.sofia.snow@gmail.com for onboarding)

    Installation Steps¶

    Quick Install (Recommended)

    1. Install UV Package Manager

    UV is a fast Python package installer:

    macOS/Linux: 

    curl -LsSf https://astral.sh/uv/install.sh | sh

    Windows (PowerShell): 

    irm https://astral.sh/uv/install.ps1 | iex

    2. Download and Install Crackz

    Using GitHub CLI (easiest): 

    # Login to GitHub (one-time setup)
gh auth login

# Download the latest wheel
gh release download --repo anaxiatech/crackz --pattern '*.whl'

# Install with uv
uv pip install crackz-*.whl

# Verify installation
crackz --version

    Using web browser (alternative): 1. Navigate to: https://github.com/Anaxiatech-AB/crackz/releases 2. Download the latest crackz-VERSION-py3-none-any.whl file 3. Install it: 

    uv pip install crackz-VERSION-py3-none-any.whl

    3. Run Crackz

    # CLI tool
crackz --help

# GUI application
crackz-gui

    Manual Installation (Advanced Users)

    If you prefer manual control:

    1. Install Python

    If you don't have Python installed: - Download from python.org - Important: During installation, check "Add Python to PATH"

    2. Verify Python Installation

    Open a terminal/command prompt and run: 

    python --version
    You should see Python 3.11.x, 3.12.x, or 3.13.x

    3. Install UV Package Manager (Recommended)

    UV is a fast Python package installer that makes installation easier:

    macOS/Linux: 

    curl -LsSf https://astral.sh/uv/install.sh | sh

    Windows (PowerShell): 

    Invoke-RestMethod https://astral.sh/uv/install.ps1 | Invoke-Expression

    Restart your terminal after installation.

    4. Create a Virtual Environment

    This keeps Crackz isolated from other Python packages:

    Using UV (recommended): 

    uv venv crackz-env

    Using Python venv:

    Windows: 

    python -m venv crackz-env
crackz-env\Scripts\activate

    macOS/Linux: 

    python -m venv crackz-env
source crackz-env/bin/activate

    5. Download the Wheel File

    Option A: Using GitHub CLI (easiest): 

    # Install GitHub CLI first if needed
# macOS: brew install gh
# Windows: winget install --id GitHub.cli
# Linux: https://github.com/cli/cli/blob/trunk/docs/install_linux.md

# Authenticate
gh auth login

# Download latest release wheel
gh release download --repo anaxiatech/crackz --pattern '*.whl'

# Or download specific version
gh release download v0.40.0 --repo anaxiatech/crackz --pattern '*.whl'

    Option B: Manual download:

    Get the .whl file from your Crackz provider or from GitHub Releases:

    • CPU version (default): crackz-VERSION-py3-none-any.whl
    • GPU version (CUDA 11.8): crackz_cu118-VERSION-py3-none-any.whl
    • GPU version (CUDA 12.8): crackz_cu128-VERSION-py3-none-any.whl

    Replace VERSION with the actual version number (e.g., 0.40.0)

    6. Install the Wheel

    Navigate to the folder where you downloaded the wheel file and run:

    Using UV (recommended): 

    uv pip install --python crackz-env crackz-VERSION-py3-none-any.whl

    Using pip: 

    pip install crackz-VERSION-py3-none-any.whl

    For example: 

    # Using UV
uv pip install --python crackz-env crackz-0.40.0-py3-none-any.whl

# Or using pip
pip install crackz-0.40.0-py3-none-any.whl

    7. Verify Installation

    If using venv activation: 

    crackz --version

    If using UV without activation: 

    crackz-env/bin/crackz --version  # macOS/Linux
crackz-env\Scripts\crackz.exe --version  # Windows

    You should see the Crackz version number.

    Quick Start After Installation¶

    # Create a new project
crackz init --name myproject

# View help
crackz --help

    Option B: Standalone Executable (No Python Required)¶

    The easiest option - no Python installation needed!

    Requirements¶

    • Windows 10/11, macOS, or Linux
    • No Python required
    • ~250 MB disk space

    Installation Steps¶

    1. Download the Executable

    Get the executable from your Crackz provider or from GitHub Releases:

    Windows: - crackz.exe - Command-line interface - crackz-gui.exe - Graphical interface (double-click to run)

    macOS/Linux: - crackz - Command-line interface - crackz-gui - Graphical interface

    2. Install the Executable

    Windows:

    Option 1 (Easy - Run from Downloads): - Keep the executables in your Downloads folder - Double-click crackz-gui.exe to launch the GUI - Or open Command Prompt in the Downloads folder and run crackz.exe --help

    Option 2 (Advanced - Add to PATH): 

    REM Create a folder for Crackz
mkdir C:\Programs\Crackz

REM Move the downloaded files there
move %USERPROFILE%\Downloads\crackz.exe C:\Programs\Crackz\
move %USERPROFILE%\Downloads\crackz-gui.exe C:\Programs\Crackz\

REM Add to PATH so you can run from anywhere
setx PATH "%PATH%;C:\Programs\Crackz"

    macOS/Linux:

    Option 1 (Easy - Run from Downloads): 

    # Make executable
cd ~/Downloads
chmod +x crackz crackz-gui

# Run the GUI
./crackz-gui

# Or run CLI
./crackz --help

    Option 2 (Advanced - Install to system): 

    # Make executable
chmod +x crackz crackz-gui

# Move to system directory
sudo mv crackz /usr/local/bin/
sudo mv crackz-gui /usr/local/bin/

# Now you can run from anywhere
crackz --help

    3. Run Crackz

    GUI (Graphical Interface): - Windows: Double-click crackz-gui.exe - macOS/Linux: Run ./crackz-gui or crackz-gui (if installed to PATH)

    CLI (Command Line): 

    crackz --version
crackz --help

    Quick Start After Installation¶

    Using the GUI: 1. Launch crackz-gui 2. Click "New Project" to create a new project 3. Import your images 4. Run crack detection

    Using the CLI: 

    # Create a new project
crackz init --name myproject

# View help
crackz --help

    Troubleshooting¶

    Python Wheel Installation Issues¶

    Problem: "python: command not found" - Python is not installed or not in PATH - Solution: Reinstall Python and check "Add Python to PATH" during installation

    Problem: "pip: command not found" - pip is not in PATH - Solution: Try python -m pip install crackz-VERSION.whl instead

    Problem: Installation fails with permission error - Solution: Use a virtual environment (see step 3 above) - Or on Linux/macOS: pip install --user crackz-VERSION.whl

    Standalone Executable Issues¶

    Problem: Windows Defender blocks the executable - This is normal for unsigned executables - Solution: Click "More info" → "Run anyway"

    Problem: "Permission denied" on macOS/Linux - The file is not executable - Solution: Run chmod +x crackz or chmod +x crackz-gui

    Problem: Slow first startup (~30 seconds) - This is normal - the executable extracts files on first run - Subsequent starts will be faster

    Problem: Antivirus flags the executable - PyInstaller executables sometimes trigger false positives - Solution: Add to your antivirus exceptions

    Which Installation Method Should I Choose?¶

    Feature Wheel (Option A) Executable (Option B)
    Python Required ✅ Yes ❌ No
    File Size ~50 MB ~250 MB
    Setup Complexity Medium Very Easy
    Best For Python users, developers Non-technical users
    Updates Easy with pip Download new version

    Recommendation: - Choose Option B (Executable) if you want the easiest setup - Choose Option A (Wheel) if you already have Python and prefer smaller downloads
