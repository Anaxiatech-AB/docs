    GitHub Models Integration¶

    Status: Implemented Last Updated: 2025-11-15

    Overview¶

    Crackz uses GitHub Models (AI inference API) to automate development workflows through GitHub Actions. GitHub Models provides free, rate-limited access to leading AI models (GPT-4, Claude, Llama, etc.) directly through GitHub's infrastructure.

    Key Benefits: - 🤖 Automated release notes generation (English + Swedish) - 🏷️ Intelligent issue triage and labeling - 📝 PR description auto-generation - 💰 Cost-effective (~$3-5/month estimated) - 🔒 Privacy-preserving (no data training)

    Implemented Workflows¶

    1. AI-Enhanced Release Notes¶

    File: .github/workflows/ai-release-notes.yml

    Trigger: Automatically after Release workflow completes, or manual dispatch

    What it does: - Generates customer-friendly release notes from technical changelogs - Translates notes to Swedish for local customers - Updates GitHub releases with enhanced descriptions - Archives notes as workflow artifacts

    Example: 

    # Manual trigger for a specific release
gh workflow run ai-release-notes.yml -f version=v0.60.0

    Outputs: - Updated GitHub release with AI-generated notes - Swedish translation as release asset - Archived notes in workflow artifacts

    2. AI Issue Triage¶

    File: .github/workflows/ai-issue-triage.yml

    Trigger: When a new issue is opened

    What it does: - Analyzes issue content with AI - Automatically applies labels: - Type: bug, feature, question, docs, enhancement - Priority: low, medium, high, critical - Component: cli, gui, training, detection, docker, etc. - Adds needs-info label if issue lacks details - Posts AI reasoning as comment

    Example labels applied: 

    type: bug
priority: high
component: training
needs-info
ai-triaged

    Fallback: If AI fails, applies needs-triage label for manual review

    3. AI PR Description Generator¶

    File: .github/workflows/ai-pr-description.yml

    Trigger: When a PR is opened (if no description or labeled ai-description)

    What it does: - Analyzes code changes (diff, changed files) - Generates structured PR description: - Summary of changes - List of main changes - Type of change checklist - Testing checklist - Review checklist - Skips PRs with >50 changed files (size limit)

    Example: 

    ## Summary
This PR adds GitHub Models integration for automated workflows.

## Changes
- Added AI-powered release notes generation
- Implemented issue triage automation
- Created PR description generator

## Type of Change
- [x] New feature (non-breaking change which adds functionality)
- [ ] Bug fix
...

    Prompt Templates¶

    All AI prompts are stored in .github/prompts/ for easy customization:

    Template Purpose Model Max Tokens
    release-notes.prompt.yml Generate customer-friendly release notes GPT-4o 2000
    issue-triage.prompt.yml Categorize and label issues GPT-4o-mini 300
    pr-description.prompt.yml Generate structured PR descriptions GPT-4o 800

    Editing prompts: Modify YAML files in .github/prompts/ to customize AI behavior.

    Cost Control¶

    Rate Limits (Free Tier)¶

    GitHub Models provides free access with rate limits: - Low category models (smaller): ~15 requests/min, 150/day - High category models (GPT-4, Claude): Stricter limits - Embedding models: Separate tier

    Size Limits¶

    Workflows implement size checks to control costs: - Release notes: No size limit (runs post-release) - Issue triage: Limited to 300 tokens output - PR descriptions: Skips PRs with >50 changed files

    Estimated Monthly Cost¶

    Based on expected usage: - Release notes: 10/month × 9000 tokens = $0.90 - Swedish translation: 10/month × 6000 tokens = $0.60 - Issue triage: 50/month × 800 tokens = $0.40 - PR descriptions: 40/month × 2300 tokens = $0.92

    Total estimated: $2.82/month

    For actual costs, check GitHub organization billing.

    Privacy and Security¶

    GitHub Models Guarantees: - ✅ No prompts/outputs shared with model providers (OpenAI, Anthropic, etc.) - ✅ No data used for training or improving models - ✅ Runs on GitHub/Azure infrastructure - ✅ Subject to GitHub Data Protection Agreement (DPA) - ✅ Enterprise-grade security

    Best Practices: - Workflows use GITHUB_TOKEN (no separate API keys needed) - All workflows have continue-on-error: true (don't block CI) - Large PRs are skipped to prevent excessive API calls - Sensitive data is not sent to AI (no secrets in prompts)

    Testing Locally¶

    Before modifying workflows, test prompts locally:

    Prerequisites¶

    # Install requests library
uv pip install requests

# Set GitHub token
export GITHUB_TOKEN=ghp_your_token_here  # Or set in environment

    Run Tests¶

    python scripts/test_github_models.py

    This will: - Test release notes generation - Test issue triage - Show token usage and costs - Validate API access

    Customization¶

    Modify Prompts¶

    Edit YAML files in .github/prompts/:

    # .github/prompts/release-notes.prompt.yml
system: |
  You are a technical writer for Crackz...

prompt: |
  Create customer-friendly release notes...

model: openai/gpt-4o
max_tokens: 2000

    Change Models¶

    Available models: - openai/gpt-4o - Most capable, higher cost - openai/gpt-4o-mini - Faster, cheaper, good for simple tasks - anthropic/claude-sonnet-4-5 - Alternative to GPT-4o - See full list: https://github.com/marketplace?type=models

    Adjust Behavior¶

    Modify workflow files directly: - Change size limits - Add/remove labels - Customize output format - Add fallback logic

    Troubleshooting¶

    AI Generation Failed¶

    Symptom: Workflow completes but no AI response

    Causes: - Rate limit exceeded (free tier) - API temporarily unavailable - Malformed prompt

    Solution: - Check workflow logs in GitHub Actions - Retry workflow manually - Use local testing script to debug prompts

    Incorrect Labels Applied¶

    Symptom: Issue labeled incorrectly by AI

    Solution: - Manually adjust labels (AI adds ai-triaged for tracking) - Update .github/prompts/issue-triage.prompt.yml with better instructions - Report pattern to improve prompt

    Costs Too High¶

    Solution: - Review GitHub billing dashboard - Reduce max-tokens in workflows - Increase size limits (skip more PRs/issues) - Use cheaper models (GPT-4o-mini instead of GPT-4o)

    Monitoring¶

    Track AI Quality¶

    Monitor these metrics monthly: - Release notes: Team satisfaction (survey) - Issue triage: Accuracy (manual audit 20 issues/month) - PR descriptions: Keep rate (% not edited) - Cost: GitHub billing dashboard

    GitHub Actions Insights¶

    View workflow runs: 

    gh run list --workflow=ai-release-notes.yml
gh run list --workflow=ai-issue-triage.yml
gh run list --workflow=ai-pr-description.yml
