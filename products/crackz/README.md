# Crackz - AI-Powered Crack Detection

Crackz is Anaxiatech AB's flagship product for AI-powered infrastructure crack detection and analysis.

## Overview

Advanced computer vision system designed to detect and analyze structural cracks in harbor and marine infrastructure using PyTorch Lightning-based segmentation models.

## Key Features

- **Real-time Detection**: Immediate crack identification in images
- **Batch Processing**: Large-scale analysis capabilities
- **Customizable Training**: Adapt to specific infrastructure types
- **Professional Workflow**: Structured data pipeline with train/val/test splits
- **Multiple Interfaces**: Both CLI and GUI applications
- **Flexible Deployment**: Docker support with CPU/GPU variants
