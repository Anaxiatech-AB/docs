    GitHub Billing Alerts Setup Guide¶

    Anaxiatech-AB Organization¶

    🔔 Setting Up Billing Alerts¶

    Since the GitHub API doesn't support programmatic billing alert setup, you need to configure these through the web interface.

    Step-by-Step Billing Alert Setup¶

    1. Access Billing Settings¶

    Try these URLs in order: - Primary: https://github.com/organizations/Anaxiatech-AB/settings/billing - Alternative: https://github.com/settings/billing (personal account billing) - Fallback: https://github.com/Anaxiatech-AB → Settings → Billing and plans

    2. Configure Spending Limits & Alerts¶

    For GitHub Actions: 1. Navigate to "Actions" section in billing settings 2. Set spending limit (recommended: $10-20/month) 3. Configure alert thresholds: - 50% of limit ($5-10) - 80% of limit ($8-16) - 100% of limit ($10-20)

    For GitHub Packages: 1. Navigate to "Packages" section in billing settings 2. Set spending limit (recommended: $5-10/month) 3. Configure alert thresholds: - 50% of limit ($2.50-5) - 80% of limit ($4-8) - 100% of limit ($5-10)

    For Seats (Plan Changes): 1. In "Plans and usage" section 2. Enable notifications for: - Seat additions - Plan upgrades - Billing failures

    3. Email Notification Settings¶

    Ensure billing emails go to: theresia.lundgren@anaxiatech.se

    To Update Billing Email: 1. Go to organization settings 2. Navigate to "Billing and plans" 3. Click "Billing settings" 4. Update billing email address

    🎯 Recommended Alert Thresholds¶

    Based on your current setup:

    Current Plan Costs: - Seats: $8/month (after reducing to 2 seats) - Expected Actions usage: $0-2/month - Expected Packages: $0-1/month - Total Expected: $8-11/month

    Recommended Alerts: 1. Actions Alert: $5/month (covers typical CI/CD usage) 2. Packages Alert: $2/month (covers container registry usage) 3. Total Monthly Alert: $15/month (safety buffer for unexpected usage)

    📊 Manual Monitoring Commands¶

    Since API billing access is limited, use these commands for manual monitoring:

    # Check current organization status
gh api orgs/Anaxiatech-AB --jq '{plan: .plan.name, seats: .plan.filled_seats, limit: .plan.seats}'

# Monitor repository count (affects costs)
gh api orgs/Anaxiatech-AB/repos --jq '. | length'

# Check team structure (affects complexity)
gh api orgs/Anaxiatech-AB/teams --jq '. | length'

    🤖 Automated Monitoring Script¶

    Run this monthly to track usage:

    # Monthly billing check
.\scripts\monitor-github-costs.ps1 -Detailed

# Quick status check
gh api orgs/Anaxiatech-AB --jq '{plan: .plan.name, cost_per_month: (.plan.filled_seats * 4), annual_cost: (.plan.filled_seats * 4 * 12)}'

    🚨 Cost Spike Indicators¶

    Watch for these warning signs:

    Actions Usage Spikes:¶

    • Multiple large builds running simultaneously
    • Long-running workflows (>30 minutes)
    • Inefficient workflow triggers
    • Matrix builds with too many combinations

    Package Storage Spikes:¶

    • Old container images not being cleaned up
    • Large binary artifacts
    • Duplicate package versions

    Unexpected Seat Usage:¶

    • Accidental member additions
    • Pending invitations consuming seats
    • External collaborators added as members

    🔧 Troubleshooting Billing Access¶

    If you can't access billing settings:

    Check Organization Permissions:¶

    # Verify you're an organization owner
gh api orgs/Anaxiatech-AB/memberships/theresiasnow --jq '{role: .role, state: .state}'

    Alternative Access Methods:¶

    1. Direct GitHub URL: https://github.com/Anaxiatech-AB
    2. Click: "Settings" tab
    3. Navigate: "Billing and plans" in left sidebar

    If Still No Access:¶

    1. Check if you have owner permissions (not just admin)
    2. Verify 2FA is enabled on your account
    3. Clear browser cache and try again
    4. Try incognito/private browsing mode

    📧 Email Alert Setup¶

    Set up these email filters to prioritize GitHub billing alerts:

    Email Subject Filters: - "GitHub billing" - "GitHub Actions usage" - "GitHub Packages usage" - "Anaxiatech-AB billing"

    Recommended Action: - Create a dedicated folder/label for GitHub billing - Set up high-priority notifications - Forward to relevant team members if needed

    📈 Monthly Billing Review Checklist¶

    □ Check total monthly cost vs budget
□ Review Actions minutes usage
□ Monitor Packages storage usage
□ Audit organization members
□ Verify no unexpected charges
□ Update billing alerts if needed
□ Archive old packages/artifacts
□ Optimize workflows if usage is high

    🎯 Cost Control Best Practices¶

    1. Set Conservative Limits: Start low, increase as needed
    2. Regular Reviews: Monthly billing audits
    3. Automated Cleanup: Remove old packages/artifacts
    4. Workflow Optimization: Efficient CI/CD patterns
    5. Member Management: Regular seat audits
